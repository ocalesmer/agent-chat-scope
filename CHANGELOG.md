# Changelog

## 0.1.1

- Open selected Codex conversations in the Codex sidebar using the installed OpenAI extension's local conversation URI handler.
- Keep terminal resume available in the context menu and offer it when Codex navigation fails.
- Cover sidebar navigation, extension activation, unavailable integrations, and terminal fallback with command tests.

## 0.1.0

- Add a project-scoped sidebar for local Codex and Claude Code conversations.
- Support multi-root workspaces, optional subfolder matching, all-project browsing, title search, and refresh.
- Resume a conversation through its provider CLI in its original directory.
- Include fixture-based adapter tests and cross-platform project-boundary tests.
